# fonts/

`Inter-Bold.ttf` — fonte Inter 4.0 (rsms/inter), licença SIL Open Font License 1.1 (`Inter-LICENSE-OFL.txt`): uso comercial e redistribuição permitidos.

É a primeira da lista de prioridade (`config.json > fonts.priority`). Para trocar a identidade visual, coloque aqui outro `.ttf` (Montserrat, Poppins, Manrope...) e ele será usado se a família estiver mais acima na lista; ajuste a ordem em `config.json`.
